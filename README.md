# FastAPI Backend Learning Projects

Репозиторий с практическими проектами по созданию асинхронного бэкенда на FastAPI и PostgreSQL.

## Стек технологий
- Python 3
- FastAPI (веб-фреймворк)
- PostgreSQL (реляционная СУБД)
- SQLAlchemy 2.0 (асинхронная ORM)
- Alembic (миграции базы данных)
- Pydantic v2 (валидация данных)

## Наши проекты в репозитории:
1. 🗓️ **Task Tracker API (Ветка main):** Простейший бэкенд для списка задач. Базовый CRUD, знакомство с асинхронным подключением к БД и первыми миграциями.
2. 🛒 **Mini-Marketplace API (Ветка feat/marketplace — в разработке):** Каталог товаров интернет-магазина. Изучение связей между таблицами (One-to-Many), каскадного удаления и продвинутых операций валидации Pydantic.

## Как запустить локально
1. Клонировать репозиторий.
2. Создать и активировать виртуальное окружение: `venv\Scripts\activate`
3. Установить зависимости.
4. Создать файл `.env` в корне и указать `DATABASE_URL=postgresql+asyncpg://postgres:ПАРОЛЬ@localhost:5432/имя_базы`
5. Применить миграции базы данных: `alembic upgrade head`
6. Запустить сервер: `fastapi dev main.py`
